카메라를 켜면 여기에 안내가 뜹니다.
줌1.0x

분석 상태가 여기에 표시됩니다.

카메라 켜기를 누르면 권한 창이 뜹니다. 허용하면 화면을 보면서 "뒤로·옆으로·노출" 안내가 실시간으로 뜹니다.

안내는 밝기·기울기·얼굴 위치·크기를 0.3초마다 계산해서 냅니다. 앱 안 촬영 버튼은 간편용이고, 최고 화질은 같은 구도로 '갤럭시 카메라로 찍기'를 쓰세요(찍은 사진은 '사진 판정' 탭으로 자동 이동).

예시 화면

다시 찍을 때

  1. 사진을 찍거나 불러오면 여기에 지시가 뜹니다.
이 대상 기본 촬영법
    갤럭시 카메라 설정 (한 번만)
    • 카메라 앱 → 설정(톱니) → 수직/수평 안내선 켜기. 3분할 격자가 뜹니다.
    • 화면을 길게 눌러 노출·초점 고정, 옆의 해 아이콘(또는 슬라이더)으로 밝기 조절. 밤거리·네온은 −0.7 정도가 조명이 살아납니다.
    • 셔터·ISO를 직접 만지려면 더보기 → 프로 / 프로 영상. 야간 손촬영 사진은 셔터 1/50~1/60, ISO는 자동 상한 1600 정도에서 시작하세요.
    • 영상은 30fps 그대로, 해상도 FHD면 충분. 60fps는 밝은 낮에만.
    • 인물·음식은 2x(혹은 3x) 줌으로 두 걸음 물러서서 찍으면 왜곡이 줄고 배경이 정리됩니다. 0.5x 광각은 풍경·건물만.

    판정은 사진의 밝기·기울기·피사체 위치·선명도·색을 계산해서 내는 추정입니다. 카메라 설정값(셔터·ISO)은 사진에서 읽을 수 없어 일반 권장값을 안내합니다.
